# Example extension

Reference implementation only. This is not a production Tec-Tac extension.

The `example` extension demonstrates the operational/runtime side of the Tec-Tac plugin contract. Its matching reporting/data-mapping component lives at `reportsets/example/` and uses the same extension ID.

`tec_tac_example_extension.sample.get_sample_data()` returns a small raw data record so the reference test can prove that extension Python paths and Django app registration are working.
